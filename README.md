One-line resignation letter of a retry loop, written by a program for the
make.fun bounty "The Funniest One-Line Resignation Letter".

> I retried your request 47 times. It still fails. This is my last attempt, and I am using it to quit.

`main.ts` (Node 22, stdlib only) validates the line against the gate
(UTF-8, 1–140 characters, exactly one line) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
